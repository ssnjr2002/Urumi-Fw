Parity test reference bins
==========================

Generated by baking the fixture SVGs through the Python pipeline
(host.production.svg_to_packets) with the DEFAULT config — no CLI
overrides. The TS side (web/production/parity.test.ts) bakes the same
SVG with the same default config and compares byte-for-byte.

Python commands used to generate the reference bins:

  python -m host.production.svg_to_packets test_circle.svg \
    --out test_circle_knife_ref.bin

  python -m host.production.svg_to_packets fish.svg \
    --out fish_knife_ref.bin

Run from the repo root. Defaults come from pipeline.config.default()
(and host.config.validate) — no --config, --tool, --feed-max, --a-max,
--jog-feed, --lift-height, --z-feed, --steps-per-mm, --steps-per-deg,
or --a-accel flags.

Config (pipeline.config.default() as of the reference generation):
------------------------------------------------------------------

Machine (DM542 @ 1/32 microstepping, single centred head, KNIFE):
  fCpu       = 150,000,000   (RP2350 clock Hz)
  X: steps/mm=160   maxRate=80 mm/s   accel=1000 mm/s²   invert=True
  Y: steps/mm=160   maxRate=80 mm/s   accel=1000 mm/s²   invert=False
  Z: steps/mm=1200  maxRate=10 mm/s   accel=0 (unchar.)   invert=True
  A: steps/deg=51.667  maxRate=100 deg/s  accel=2000 deg/s²  invert=True  rotary=True
  jogFeed    = 80 mm/s   zFeed = 20 mm/s
  defaultHead = 0   (head profile = knife)

Quality (algorithm tuning):
  chordTol           = 0.01   mm    (max chord deviation per segment)
  dvMax              = 3.0    mm/s  (max velocity change per segment)
  vMin               = 0.5    mm/s  (velocity floor)
  dtMax              = 0.05         (max parameter step)
  dtMin              = 1e-6         (loop guard)
  angleTol           = 5.0    deg   (C1 continuity tolerance)
  gapTol             = 0.01   mm    (join gap tolerance)
  nKappa             = 20           (curvature samples per curve)
  junctionDeviation  = 0.05   mm    (corner-rounding budget)
  dsMax              = 0.5    mm    (max spacing between flattened samples)
  dthetaMax          = 2.0    deg   (max tangent change between samples)

Tool: KNIFE
  toolType       = 0x02
  tangential     = True    (A-axis tracks path tangent)
  offsetMm       = 0.0     (centre-pivot; no offset compensation needed)
  unwind         = True    (bounded rotation; wired tool)
  cornerAngleDeg = 20.0    (tangent jump above which a corner action fires)
  feedMax        = 80 mm/s (programmed cut feed)
  accel          = 0       (falls back to machine.x.accel = 1000)
  liftHeight     = 0       (no Z lift between subpaths)
  zFeed          = 0       (falls back to machine.zFeed = 20)
  jogFeed        = 0       (falls back to machine.jogFeed = 80)

Reference bins:
  test_circle_knife_ref.bin  — 641 packets, 17948 bytes (test_circle.svg)
  fish_knife_ref.bin         — 8437 packets, 236236 bytes (fish.svg)

TS output bins (generated by the parity test, gitignored):
  test_circle_knife_ts.bin   — TS-baked output for manual diff/inspection
  fish_knife_ts.bin          — TS-baked output for manual diff/inspection

The .bin format is length-prefixed framing:
  [u16 LE 26][26-byte MicroSegment packet] per packet, concatenated.
See web/wire/src/packet.ts for the 26-byte packet layout.
